# Test evidence index

This directory indexes raw command outputs. Files are copied or regenerated by the
evidence commands; no output here is hand-written from memory.

| Artifact | Command | Status |
|---|---|---|
| `pytest_full.txt` | `python -m pytest -q` | Last archived run: 164 passed in 10.20 s |
| `pytest_junit.xml` | `python -m pytest -q --junitxml=...` | Not generated in the final session |
| `ruff.txt` | `python -m ruff check .` | All checks passed at last run |
| `synthetic_evaluation.json` | `python scripts/evaluate_synthetic.py` | Synthetic 8/8 contract checks |
| `latency_report.json` | `python scripts/benchmark_latency.py --runs 10 --warmup 2` | Measured CPU latency |

| `baseline_evaluation.json` | `python scripts/evaluate_baseline.py ...` | BLOCKED (no real data) |
| `training_blocked.json` | `python scripts/train_segmentation.py` | BLOCKED (no training) |

Raw reports also live under `reports/`. The mandatory evaluator report is
`reports/DEMO_REPORT.md`.

## Important honesty note

`synthetic_evaluation.json` and the failure gallery are synthetic checks. They are
not real-produce accuracy, not a real failure gallery, and not model performance.
`baseline_evaluation.json` and `training_blocked.json` are refusal records, not
passing evaluations.
