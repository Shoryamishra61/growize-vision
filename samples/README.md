# Samples

No licensed real vegetable images are included in this repository. No real image was
used as accuracy evidence, and no real measured dataset was supplied.

## What is included elsewhere

- `data/demo/` contains **synthetic fixtures** generated by
  `scripts/create_demo_assets.py` for contract and geometry tests. They are not real
  produce samples and must not be counted as accuracy.
- `assets/aruco_marker_0_50mm.png` is the printable reference marker.
- `reports/failure_gallery/` contains synthetic refusal diagnostics.

## If real samples are supplied later

Place them outside version control until licence/consent is recorded, then create a
manifest using `data/dataset_manifest_template.json`. Every image needs:

- a unique specimen ID and physical measurement;
- crop, unit, metric, lot, capture session, source, licence, consent;
- a SHA-256 hash and relative path.

Run `python scripts\validate_dataset.py --manifest <path>` before any evaluation. Do
not add unlicensed web images or unmeasured images as accuracy evidence.
