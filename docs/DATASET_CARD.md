## 2. Included synthetic demo set

`data/demo/demo_manifest.json` lists vector-defined fixtures generated by
`scripts/create_demo_assets.py`. Every entry has:

- `fixture_id`, relative path, SHA-256;
- `synthetic: true`;
- crop, physical unit, metric;
- vector-defined `actual_metric_mm` where applicable;
- expected demonstration class/status;
- demo threshold and nominal marker side;
- a warning that it is not real produce.

Fixtures cover: potato small/big, okra small/big, missing marker, empty mat, blur,
edge clipping, and a synthetic MP4. These verify calibration plumbing, geometry,
status precedence, media handling, and MP4 export. They are **not** a sample of the
real distribution and must never be counted as accuracy.

## 3. Real-data template

`data/dataset_manifest_template.json` is an empty, intentionally failing template.
Required provenance fields:

- dataset name, owner, collection protocol, licence, source, consent/ethics;
- `contains_personal_data` explicitly true/false.

Required per-specimen fields:

| Field | Requirement |
|---|---|
| `specimen_id` | Unique stable ID |
| `crop` | Configured crop key |
| `physical_unit` | `single_tuber`, `single_bulb`, `single_fruit`, `single_pod`, `single_leaf`, `standardized_bunch` |
| `measured_metric` | One of the four policy metrics |
| `measurement_1_mm` | Positive caliper/ruler measurement |
| `measurement_2_mm` | Independent repeat measurement (recommended) |
| `reference_grade` | `SMALL` or `BIG` after the frozen policy is applied |
| `synthetic` | `false` for real produce |
| `lot` | Physical lot/batch, used for grouping |
| `capture_session` | Capture session ID |
| `source`, `license`, `consent` | Provenance; `unknown`/`TBD` rejected for real data |
| `images` | Relative path, 64-char lowercase SHA-256, optional role |

The validator also rejects duplicate specimen IDs, duplicate image hashes, absolute
or traversing paths, missing files, hash mismatches, unsupported units/metrics, and
a group (lot/session/specimen) appearing in more than one split.

## 4. Collection protocol (not yet executed)

1. Obtain specimens from a known source; record lot, date, and custodian.
2. Assign a specimen ID before photography.
3. Measure the policy metric at least twice with a ruler/caliper; record observer,
   tool, and disagreement.
4. Apply the frozen policy to derive `SMALL`/`BIG`; never adjust labels after seeing
   model output.
5. Capture 6–10 views per specimen across at least two lighting conditions and two
   positions/angles, with the measured marker visible on the same plane.
6. Include hard negatives: no object, no marker, blur, clipping, occlusion, multiple
   objects, cluttered background, lookalikes.
7. Record licence and consent for every image and every person visible.
8. Hash images at ingestion and write the manifest.
9. Run `python scripts\validate_dataset.py --manifest <path>`.
10. Run `python scripts\group_split.py --manifest <path>` once, freeze the split,
    and keep the test set sealed.

## 5. Split protocol

- Group key: `lot`, else `capture_session`, else `specimen_id`.
- All frames/views of one specimen stay in one split.
- Deterministic greedy assignment by a seeded SHA-256 group order, targeting
  70/15/15 by default.
- At least one group per split is required, so very small datasets cannot produce a
  defensible three-way split.
- Synthetic entries are excluded from real accuracy claims even if present in a
  manifest.

## 6. Licensing and privacy

- No real images are included, so there is no real-data redistribution grant to
  audit.
- The app performs no cloud upload and does not export raw uploads by default; it
  exports annotated output and audit JSON/CSV.
- A real dataset must not enter the repository until licence, consent, and
  commercial-use terms are recorded. `LICENSE_UNCLEAR` is a rejection state.
- Do not log faces, identity documents, or unnecessary personal data.

## 7. Intended and prohibited uses

**Intended:** controlled-station engineering evaluation, binary size-policy
demonstration, calibration/metrology research, dataset-gate development.

**Prohibited:** claiming real-produce accuracy, buyer compliance, food safety,
yield, soil/nutrition status, autonomous sorting readiness, or coverage of
unmeasured crops from this dataset.

## 8. Next data milestone

Minimum credible pilot: 60–100 physically measured specimens with repeat
measurements, 6–10 views each, QA'd masks, and a sealed 15–20 specimen test set.
Until that exists, every real-produce metric remains `NOT EVALUATED`.
